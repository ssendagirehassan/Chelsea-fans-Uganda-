# Chelsea Fans Uganda

A responsive fan-community website prototype for Chelsea supporters in Uganda.

## Included
- Home/hero section
- Unity, love for Chelsea and community values
- Upcoming events
- Event ticketing/request form
- Community join form
- Mobile responsive design

## Going live
The included forms are demo forms. To accept real ticket payments and store registrations, connect them to a backend/database and a payment provider such as Flutterwave, Pesapal or a suitable Ugandan payment gateway.

The site is intentionally labelled as an independent fan community and does not represent Chelsea FC unless official affiliation is obtained.
